# Mathematical Model Specification

The formal mathematical specification is provided as a rendered PDF:

[Open `model_specification.pdf`](model_specification.pdf)

The LaTeX source is also included:

[Open `model_specification.tex`](model_specification.tex)

This Markdown file intentionally avoids long displayed equations because GitHub's Markdown math renderer can be brittle for multi-line stochastic-control derivations. The PDF contains the complete model statement, including:

- closed-form optimal liquidation dynamics, objective, HJB reduction, Riccati solution, and inventory path;
- symmetric limit-order market-making state dynamics, objective, Bellman equation, quote first-order conditions, boundary convention, and transformed ODE;
- first-event simulation discretization and pathwise payoff accounting.
